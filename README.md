## Epic-Seven-E7-Secret-Shop-Refresh

Fork of https://github.com/Solunium/Epic-Seven-E7-Secret-Shop-Refresh

### How to use
You can download the latest Windows executable under [releases](https://github.com/ducthanhtran/Epic-Seven-E7-Secret-Shop-Refresh/releases). After unpacking the .zip-file you can directly start the `main.exe` and follow the instructions shown in the command line interface.

Inside the game, you need to be within the secret shop first, before running the refresher.


### Develop
I have used `uv` as a package manager.

#### Requirements
- numpy
- keyboard
- opencv-python

#### Steps
1. Clone this repository
```shell
git clone https://github.com/ducthanhtran/Epic-Seven-E7-Secret-Shop-Refresh
```
2. For simplicity you can run it with `uv`. Otherwise you first need to install the required packages yourself.
```shell
uv run main.py
```
